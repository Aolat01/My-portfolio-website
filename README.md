# Aolat Adepoju — Data Science Portfolio

A responsive personal portfolio focused on the intersection of **data science, healthcare and biomedical research**.

## Built with
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Sections
- Home
- About
- Skills
- Projects
- Research
- Contact


## Before publishing
1. Replace the email placeholder in `index.html`.
2. Replace the GitHub URL.
3. Replace the LinkedIn URL.
4. Add the final CV PDF.
5. Add GitHub/live-demo links to individual projects.

## Suggested GitHub Pages deployment
Create a repository for the portfolio, upload these files, then enable GitHub Pages from the repository's Settings → Pages.
